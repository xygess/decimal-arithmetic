# Decimal Arithmetic Library

A C library for working with decimal numbers when predictable decimal calculations are preferable to binary floating-point arithmetic.

## What it does

- Represents decimal values and their sign/scale.
- Implements decimal arithmetic and comparison operations.
- Handles conversions and rounding behavior.

## Engineering focus

Numeric representations, bitwise operations, overflow handling, precision, and C library design.
